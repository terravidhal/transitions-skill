# HTML mini project

Five motionfold recipes with no build step and no dependency:

- modal
- tabs
- switch
- toast
- success check

Open `index.html` from the repository root with any static server, for example:

```bash
npm run demo
# then open http://localhost:4173/examples/mini/html/
```

The page imports the real files from `skills/motionfold/implementations/`, so it doubles as a
check that the vanilla recipe and its CSS work without a framework.
