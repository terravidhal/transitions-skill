# React mini project

Five motionfold recipes, imported from the skill:

- `modal`
- `tabs`
- `switch`
- `toast`
- `success-check`

```bash
cd examples/mini/react
npm install
npm run dev
```

The dependencies belong to this example only. The skill itself has no runtime dependency. The
Vite config allows imports from the repository root so the page uses the real recipe files instead
of copies.
